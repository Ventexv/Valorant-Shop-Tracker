# VALORANT Shop Tracker

Eine persönliche Web-App für die VALORANT-Shop-Wunschliste.

## Funktionen

- Skin-Katalog mit VP-Preisen
- Persönliche Wunschliste
- Countdown bis Mitternacht
- Für iPhone und andere Geräte geeignet

## Installation auf dem iPhone

1. Öffne die veröffentlichte Website in Safari.
2. Tippe auf „Teilen“.
3. Wähle „Zum Home-Bildschirm“.

## Hinweis

Diese Version verwendet Beispieldaten und zeigt keine echten
Shop-Angebote von Riot Games an.
